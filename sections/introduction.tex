A quick road map of this paper is as follows:

\vspace{0.1in}
\begin{itemize}
    \item In Chapter~\ref{cha:background}, we provide background on the two key challenges: providing accurate and complete context information to the LLM (Challenge 1) and ensuring fast patch generation under heavy workloads (Challenge 2). We survey existing approaches and state-of-the-art solutions for each, specifically RepoGraph \cite{ouyang2025repographenhancingaisoftware} as a context retrieval algorithm addressing Challenge 1, and CacheBlend \cite{yao2025cacheblendfastlargelanguage} as a caching algorithm targeting Challenge 2. We then motivate the need for joint optimization of both challenges.
    \item In Chapter~\ref{cha:design}, we present the design of our end-to-end system that integrates RepoGraph and CacheBlend via the \textit{Cached Context} concept, enabling position-independent KV cache reuse on context-rich agentic prompts. We also describe the system architecture, adapter module, and implementation optimizations.
    \item In Chapter~\ref{cha:eval}, we evaluate the system across four dimensions: frontend context retrieval performance across multiple LLM backends, backend KV cache reuse latency under agentic workloads, and end-to-end performance and latency of the integrated system.
\end{itemize}
